# QSlides Identity Template

Repositório template para criação de apresentações de defesa de logotipo e identidade visual utilizando o framework **QSlides Maestro**.

## 🚀 Como Iniciar

1.  **Duplicar este Repositório**: Use este repositório como base para um novo cliente de identidade.
2.  **Configurar Ativos**: Adicione as imagens e SVGs na pasta `img/`.
3.  **Editar Conteúdo**: Modifique o arquivo `content.md` com a estratégia e estrutura dos slides.
4.  **Build**:
    ```bash
    npm install
    npm run build
    ```
5.  **Visualizar Localmente**:
    ```bash
    npm run dev
    ```

## 📐 Layouts Específicos (Identity)

Este template utiliza o modelo `q-identidade` do core e suporta os seguintes layouts exclusivos no `content.md`:

-   `intro-quote`: Slide de frase com imagem de fundo.
-   `logo-fusion`: Apresenta a união de símbolos com o sinal de `+`.
-   `logo-presentation`: Exibe o logotipo ou vídeo (YouTube/R2).
-   `logo-defense`: Layout dividido para logo vertical e texto de defesa.
-   `logo-horizontal`: Exibe o logo horizontal centralizado.

## 📁 Estrutura de Arquivos

-   `content.md`: SSoT (Single Source of Truth) da apresentação.
-   `img/`: Imagens do projeto, mockups e logotipo.
-   `public/`: Resultado do build (não editar manualmente).
